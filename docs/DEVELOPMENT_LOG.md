## 二、按阶段记录

### 2026-11-23（周一）M0：选题与测试 seam
**今日进展**：选择题目二“校园二手交易平台”。按照 `tdd` skill 先确定外部 seam：Flask test client 访问页面和表单接口，只观察用户可见行为与数据库持久化结果，不针对私有函数写测试。
**遇到问题**：题目包含上传、收藏、留言、分页等多个边界，若不先定范围容易过度设计。按 `ponytail` 规则先列出“用户必须完成的事”，不做后台管理、聊天、支付和复杂 Ajax。
**产出**：路由清单、页面清单、验收清单。
**里程碑**：M0 ✅

### 2026-11-23（周一）M1：数据库与 seed
**今日进展**：建立 6 张表：users、categories、products、product_images、favorites、messages。收藏和商品图片使用独立表；留言通过 parent_id 表示卖家回复。seed 生成 24 件商品、2 个用户和示例留言。
**遇到问题**：seed 首次状态值写成 `off_sale`，与 ENUM 的 `offline` 不一致，测试库执行时报错。详见 DEBUG-002。
**产出**：`database/schema.sql`、`database/seed.sql`、`database/init.sql`。
**里程碑**：M1 ✅

### 2026-11-23（周一）M2：首页、搜索与分页
**今日进展**：按红-绿循环先写首页 10 条分页测试，再实现 COUNT + LIMIT/OFFSET。搜索同时匹配标题和描述；特殊字符 `%`、`_` 用 `LIKE ... ESCAPE '='` 转义，单引号完全交给参数化查询。
**遇到问题**：需要区分“通配符”和“用户输入的字面百分号”，否则搜索 `%` 会匹配全部商品。详见 DEBUG-001。
**产出**：首页、分类筛选、搜索、分页模板与查询。
**里程碑**：M2 ✅

### 2026-11-23（周一）M3：发布与图片上传
**今日进展**：实现发布表单。先写失败测试：未登录应跳转、无图 400、超 2MB 400、错误格式 400、成功发布写入商品和 2 张图片。上传文件先全部校验再保存，使用 UUID 文件名。
**遇到问题**：如果边校验边保存，后面的图片失败会留下孤立文件。改为先收集并校验全部图片，再统一落盘；数据库异常时清理已写文件。
**产出**：`/publish` 页面、图片预览、上传校验。
**里程碑**：M3 ✅

### 2026-11-23（周一）M4：收藏、留言与个人中心
**今日进展**：完成收藏重复提示、详情页留言、卖家回复、商品状态切换和删除。个人中心提供“我发布的 / 我的收藏 / 我收到的留言”三个 tab。
**遇到问题**：买家如果直接构造回复 POST，会绕过页面按钮。增加后端 seller_id 校验，非卖家返回 403。详见 DEBUG-004。
**产出**：完整业务闭环：发布 → 浏览 → 搜索 → 收藏 → 留言 → 回复。
**里程碑**：M4 ✅

### 2026-11-23（周一）M5：测试、截图与报告
**今日进展**：执行 `pytest -q`，10 个 HTTP 层测试全部通过。启动 MySQL 8 + Flask，用 Chrome + Playwright 完成首页、特殊搜索、详情、收藏、发布、个人中心、留言和移动端截图，控制台错误为 0。
**遇到问题**：自动化脚本最初点击“收藏商品”，但未登录页面显示“登录后收藏”，导致等待超时；改为按真实登录状态选择按钮。详见 DEBUG-005。
**产出**：10 张截图、Word/PDF 报告、开发日志、Debug 日志、AI 协作记录。
**里程碑**：M5 ✅ 本地交付完成
